  1. Question 1What distinguishes an Uptime Institute Tier II facility from Tier I?
    Show answer

    Answer: redundant capacity components. Tier I is basic capacity with no redundancy, and Tier II adds redundant components but keeps a single distribution path, so path maintenance still needs a shutdown. Concurrent maintainability is Tier III and fault tolerance is Tier IV. Read the Tiers guide.

  2. Question 2A facility can take any component or distribution path offline for planned maintenance without shutting down IT, but it is not designed to ride through every unplanned failure automatically. Which Tier does that describe?
    Show answer

    Answer: Tier III, concurrently maintainable. Tier III has redundant components and multiple distribution paths, so planned work never forces an outage. Tier IV adds fault tolerance: a single unplanned failure of any component or path does not affect the critical load. Tier Infrastructure Fundamentals compares the two.

  3. Question 3A site needs 1,000 kW of UPS capacity for its IT load. How much UPS capacity does a 2N design install?
    Show answer

    Answer: 2,000 kW in two independent systems. N is 1,000 kW, and 2N means two complete systems that can each carry the full load alone. An N+1 design built from four 250 kW modules would install 1,250 kW. See the redundancy table.

  4. Question 4How does ANSI/TIA-942 label its levels of data center infrastructure?
    Show answer

    Answer: Rated-1 to Rated-4. TIA uses "Rated" levels to avoid confusion with Uptime Institute Tiers, and it rates telecommunications, electrical, architectural, and mechanical infrastructure. A TIA-942 rating and an Uptime Tier certification come from different organizations with different criteria. Data Center Design Fundamentals covers both systems.

  5. Question 5A provider markets a new building as "Tier III", but Uptime Institute has never certified it. What does that claim usually mean?
    Show answer

    Answer: Tier III design intent, not a certification. Uptime Institute certifies design documents, constructed facilities, and operational sustainability, and a buyer can ask for those certificates. The 99.982 percent figure is a commonly quoted industry number, not part of the Tier Standard. Read the Tiers guide.

  6. Question 6In common industry usage, what happens during Level 5 commissioning?
    Show answer

    Answer: integrated systems testing. The common sequence is L1 factory acceptance, L2 delivery and installation inspection, L3 pre-functional checks and start-up, L4 functional performance testing, and L5 IST, such as a simulated utility outage with load banks running. Terms vary between firms. Read the commissioning guide.

  7. Question 7What is "stranded capacity" in a data center?
    Show answer

    Answer: capacity that cannot be used because another resource runs out first. For example, a row may have spare UPS capacity while its cooling is maxed out, so that power is stranded. Planners track power, cooling, space, and network together to avoid it. Capacity Planning & Forecasting covers how to measure it.

  8. Question 8All else being equal, which candidate site is the poorest choice for a new data center?
    Show answer

    Answer: the floodplain under the flight path. Site selection screens for natural hazards like floods, earthquakes, and wildfire, and for man-made ones like flight paths, rail lines, and pipelines. Power availability, diverse fiber, water, and permitting are weighed alongside them. Data Center Design Fundamentals covers site selection.

  9. Question 9A facility is quoted at 99.982 percent availability. About how much downtime per year does that allow?
    Show answer

    Answer: about 1.6 hours. 100 minus 99.982 leaves 0.018 percent, and 0.018 percent of 8,760 hours is about 1.6 hours. This percentage is often quoted for Tier III, but it is an industry rule of thumb, not part of Uptime's Tier Standard. Try the uptime calculator.

  10. Question 10Why does a design with N+1 UPS modules feeding a single output path fall short of concurrent maintainability?
    Show answer

    Answer: the single path still needs a shutdown. Redundant modules protect against a module failure, but concurrent maintainability also needs redundant distribution paths, so switchboards, PDUs, and feeders can be serviced while IT stays up. N+1 on one path is a Tier II-style design. Tier Infrastructure Fundamentals covers path redundancy.
