**Short answer:** Sensor acceptance should verify identity, placement, scaling, alarm logic, trend continuity, and comparison with a suitable reference before the point is treated as operational.

## Why it matters

A physically installed sensor can still be mis-scaled, mapped to the wrong point, or placed where it does not represent the intended condition.

## What to check

- Confirm point mapping and units
- Check placement against approved design
- Compare readings against a reference
- Test alarm and trending behavior

## Example from the field

A new rack inlet sensor reports a plausible number but is mapped to the adjacent rack in DCIM. Acceptance review catches the error before the dashboard is relied upon.

## Follow-up question

### Does a plausible reading prove correct sensor installation?

No. Validate mapping, units, placement, and control behavior as part of acceptance.
